# 실험 근거와 최종 모델 선택

[프로젝트 개요](../README.md) · [최종 모델 코드](final-model.md)

이 문서는 저장된 실험의 집계 결과를 코드와 연결한다. **Public 제출 점수, 공개 데이터의 개발 검증, 제출 패키지의 예측 일치 검증은 서로 다른 지표**다. GitHub에는 원본 데이터·행별 예측·모델 대신 집계 결과와 출처 파일의 SHA-256을 공개한다.

## 검증 설계와 지표

- 공개 입항 기록 12,222건·5,851척을 선박 단위 외부 5-fold로 분리했다. 한글 1,191건·382척과 비한글 11,031건을 포함한다.
- 학습 사전·통계·후보 특징은 내부 3-fold의 선박/행 분할 범위에서 생성한다. [데이터 흐름](architecture.md)
- 점수는 전체 fold의 언어별 정답 수·분모를 합산한 `0.7 × 한글 Top-1 + 0.3 × 비한글 Top-1`이다. fold 점수의 단순 평균이나 오류 조건 전체의 평균이 아니다.
- 정답 후보 누락과 후보 안의 순위 오류를 구분한다. 학습·검증 변형은 프로토콜로 고정하고 효과를 비교한다.
- 95% 구간은 선박 단위 paired bootstrap 5,000회다. 반복 모델 선택·다중 비교·Public 분포 차이는 보정하지 않았다. 새 합성 조건도 같은 공개 선박에서 생성했으므로 독립적인 비공개 평가가 아니다.

## 실험 단계와 판단

| 단계 | 분리한 변경 | 결과와 다음 판단 | 근거 |
|---|---|---|---|
| 복합 오류 검증 고정 | 기준 / 증강 확대 / 증강+교차 학습 오답 선택 | 이름 삭제·정보 결측은 개선, 이름 교환+톤수 ×0.70은 악화. 오답 선택의 추가 효과는 작고 일관되지 않음 | [12조건·3모델 집계](evidence/compound-errors.json) · [분석](experiments/compound-errors-5fold.md) · [프로토콜](../portmatch/compound_protocol.py) |
| 조합 증강 × 한글 검색 | 증강 대조군 / 조합 증강 / 검색 확대 / 둘 다, 직전 제출 최고 포함 | 대조군 대비 ×0.70은 각각 +13.09 / +2.82 / +20.03%p. 그러나 동시 적용 ×0.55는 직전 제출 최고보다 −8.02%p | [16조건·5방법 집계](evidence/joint-search.json) · [분석](experiments/joint-search-5fold.md) · [프로토콜](../portmatch/joint_search_protocol.py) |
| 넓은 톤수 보강과 추가 오답 학습 | 넓은 증강+검색 후보 학습 / 동일 예제의 오답 선택 보강, 검색 적용 여부 | ×0.55의 중간 모델 47.23% → 기본 보강 71.13% / 집중 오답 72.04%. 집중 오답+검색을 별도 제출해 Public 최고 갱신 | [20조건·7방법 집계](evidence/tonnage-repair.json) · [분석](experiments/tonnage-repair-5fold.md) · [프로토콜](../portmatch/tonnage_repair_protocol.py) |
| 최종 모델 기준 후속 보강 | 이름만 / ×0.70 주변 톤수 / 둘 다 | 목표 조건의 개선과 ×0.55 손실이 함께 발생. 세 모델 모두 미채택 | [25조건·4방법 집계](evidence/focused-replay.json) · [분석](tonnage-repair.md) · [프로토콜](../portmatch/focused_replay_protocol.py) |

세 번째 실험의 `broad`는 **넓은 증강과 추가 검색 후보의 학습 반영을 함께** 바꾼다. 이 두 요소 각각의 효과는 분리하지 못했다. `focused−broad`는 동일한 새 질의·정답·후보 수·학습 비중에서 오답 선택 정책의 추가 효과다. 검색 확대의 효과도 같은 가중치에서 비교한다.

단계별 비교 기준이 다르다. `best`는 당시 Public 0.8424607623을 낸 설정이고, `previous_search`는 중간 조합 증강+검색 설정이다. 최종 `focused_search`는 `best`보다 좋아졌지만 `previous_search`의 모든 조건을 유지하지는 못했다. 당시 유지 기준 실패를 그대로 기록하고, 별도 제출의 Public 상승을 근거로 최종 선택했다.

## 마지막 세 모델을 교체하지 않은 근거

아래는 focused_search 대비 차이(%p)다. 후보 검색·86개 특징·외부 분할은 같으며 후보 집합도 동일했다.

| 조건 | 이름 보강 | 톤수 보강 | 동시 보강 |
|---|---:|---:|---:|
| 원본 | +0.2297 | −0.1899 | −0.3608 |
| 이름 1글자 삭제 | +1.6114 | +0.0588 | +1.8944 |
| 이름 2글자 삭제 | +3.1356 | −0.3907 | +2.1626 |
| 이름 교환 + 두 톤수 ×0.70 | −0.8419 | +3.0998 | +3.0220 |
| 이름 2글자 삭제 + 두 톤수 ×0.55 | −0.6149 | −3.1770 | −3.5307 |
| 이름 2글자 삭제 + 두 톤수 ×1.50 | +1.2920 | +4.6148 | +4.8373 |

핵심 유지 조건인 원본·×0.55·×1.50은 **전체 합산과 제출용 fold0 각각 하락이 없어야** 한다. 전체 16개 유지 조건의 −0.25%p 허용 기준은 별도로 확인한다. 동시 보강의 ×0.55는 5개 fold 모두 악화됐고, 변화의 95% 구간은 [−5.4618, −1.6956]%p, 제출용 fold0 손실은 −5.8994%p였다. 해당 조건의 후보 누락은 378행으로 같지만 순위 오류가 587→731행으로 증가했다.

따라서 세 후속 모델의 `development_point_gate_pass`와 `strict_development_gate_pass`는 모두 `false`다. 집계 JSON의 `paired_changes`, `confidence_intervals`, `fold_metrics`, `retention_gates`에서 수치와 판정을 확인할 수 있다. 새 모델의 Public 점수는 없으며 최종 focused_search를 유지했다.

## 실제 제출 결과의 확인 범위

| 제출 | Public 원점수 | 기록 근거 |
|---|---:|---|
| 첫 86개 특징 fold0 | 0.7913544371 | [제출 화면 확인 기록](experiments/first-public-submission.md) |
| robust 검색 + 톤수 결측 증강 fold0 | 0.8424607623 | [두 번째 제출 기록](experiments/second-submission.md) |
| 전체 공개훈련 모델 | 0.8324345055 | [전체훈련 비교](full-training.md) |
| 최종 focused_search fold0 | **0.8515414798** | [제출 기록 요약](evidence/submission-verification.json)의 `public` |

첫 결과는 제출 화면을 확인한 기록이며, 이후 점수는 프로젝트 소유자가 전달한 제출 결과를 기록한 것이다. 최종 서버 화면·제출번호를 독립적으로 재검증하지 않았으며, Private·최종 순위도 확인되지 않았다. Public의 첫 제출 대비 개선은 **+0.0601870427**, 백분율 환산 시 **+6.01870427%p**다. 개별 구성 요소의 Public 기여를 분리한 값은 아니다.

## 제출 패키지 검증

[검증 집계](evidence/submission-verification.json)는 완료된 전체 검증과 후속 감사 기록에서 추출했다. 원본 2,452행·역순 2,452행·부분 64행·단일 1행·오류 변형 320행·ID/연도/카탈로그 순서 변경 4행, 합계 **5,293개 예측**이 저장 결과와 같았다. 같은 기록을 여러 조건에서 실행한 횟수이며 독립적인 신규 데이터 5,293건이나 정확도 100%를 의미하지 않는다.

최종 제출 ZIP의 SHA-256:

```text
3a1afeb2751950fb487b4f412ef34c8be11545ae59c06c1ccda74077ed84d2c5
```

공개한 런타임 모듈 14개와 제출 진입점 1개의 바이트가 보존된 ZIP과 일치한다. 코드 해시는 `runtime_sources`에 기록했다. 모델 자산은 공개하지 않으므로 GitHub의 집계와 해시만으로 실제 모델 성능을 독립 재현했다는 뜻은 아니다. [추론·패키징·테스트 경로](final-model.md)

## 공개 자료 검산

저장소 루트에서 Python 3.11 표준 라이브러리만으로 실행할 수 있다. 학습이나 추론은 실행하지 않는다.

```powershell
python scripts/export_public_evidence.py --check
```

집계 356개 행의 언어별 분자·분모로 점수를 재계산하고, 쌍별 차이·이전 20조건의 기준 점수 일치·5,293개 검증 기록 합계·추론 소스 해시를 확인한다. 원본 실험 파일을 보유한 환경에서는 같은 스크립트의 `--check`를 빼면 공개용 집계를 다시 추출한다. 출처 파일의 해시는 각 JSON의 `sources`에 있으며 해당 `runs/` 파일은 로컬 보존물이다.

원본 결과·종료 보고서·모델·제출 ZIP은 변경하지 않았다. 기존 상세 문서의 ‘현재 최고’·‘다음 실행’ 표현은 각 실험 당시의 기록이며, 최종 상태는 이 문서와 [README](../README.md)를 기준으로 읽는다.
