# GT 결측 증강 5-fold — 강건성 개선 확인, 기준 교체 보류

> 공개용 정리본: 실제 선박별 입력·정답·예측·점수와 행 식별자는 제외했다. 아래 성능표는 실제 실험의 집계 수치이며, 오류의 원리는 별도의 [가상 예시](../fictional-examples.md)로 설명한다.

후속 상태(2026-10-26): **원본 질량0.75 전체 5-fold 검증을 완료했고 미채택**했습니다. 0.5는 사용자 보고 서버 최고 **0.8424607623**인 고정 fold0 제출과 후속 대조군으로 유지합니다. 기존86개 모델·첫 ZIP과 아래 10월 25일의 원본 보존 판단도 보존합니다. [0.75 전체 결과·최종 판단](gt-reweighting-5fold.md). 질량 비율 추가 탐색은 종료했습니다.

2026-10-25 당시 분석: **전체 5-fold 분석을 완료했고, `original_mass=0.5` 증강 모델의 기존 86개 기준·제출 모델 교체는 보류했습니다.** 결측·톤수 오차의 개선은 다섯 구간에서 확인됐지만 원본 한글 정답이 3건 줄었습니다. 증강 모델은 강건성 비교 대조군으로 보존하고 다음은 원본 질량 0.75 한 값을 사전 고정한 재가중치 실험입니다. 후속 [재가중치 옵션과 fold1 직접 비교](gt-reweighting.md)는 구현을 완료했고 실제 fold1 실행·분석까지 완료했습니다. [0.75 fold1 당시 결과](gt-reweighting-fold1.md)는 채택 보류·나머지 fold 진행 판단이었으며, 후속 전체 검증은 위 링크에 정리했습니다. [0.5 fold0 두 번째 제출](second-submission.md)의 사용자 보고 점수는0.8424607623입니다. 아래 수치와 감사는 이 구현 이전의 분석 기록입니다.

## 범위와 비교 무결성

분석 대상은 `runs/compare_robust_gt_missing_fold0`부터 `fold4`까지입니다. 새 fold3은 2,360행, fold4는 2,554행이며 전체는 **12,222행, 한글 1,191·비한글 11,031**입니다. 다섯 입력 조건·네 방법의 **244,440개 저장 예측**을 분석했습니다. 새로운 학습·전체 재추론은 실행하지 않았습니다.

- 현재 입력·코드·모델·인덱스·캐시 메타데이터로 다섯 fold를 재감사해 **6,502/6,502 항목 통과**. 새 fold3·4의 감사는 이 중 2,590개입니다.
- 후보 집합 해시·수·정답 포함 여부 **122,220쌍**, 세 저장 모델의 원본 예측 **36,666행**이 점수까지 일치합니다.
- 전체 검증 행은 중복·누락 없이 원본 훈련 입력을 한 번씩 포함합니다. 선박 단위 분할·seed·훈련 부분의 사전/범주 통계·특징 순서·학습 설정을 확인했습니다.
- `robust`, `reference`, `trained`는 같은 후보를 사용합니다. 증강 전후 차이는 **결측 입력 추가와 원본별 질량 정책을 함께 적용한 효과**입니다. 각각의 단독 효과를 분리하지 않았습니다.

| 방법 | 검색 | 학습 |
|---|---|---|
| 기존 86개 (`baseline`) | legacy | 채택한 기존 모델 |
| 검색만 robust (`robust`) | robust | 기존 모델 가중치 고정 |
| 증강 없는 robust (`reference`) | robust | 새 후보·오답 샘플로 재학습 |
| 증강 (`trained`) | robust | 원본 + GT 결측 3종, 원본 질량 기본 0.5 |

모든 순위 모델은 토큰·문맥 음차를 포함한 86개 특징, 300회·6스레드입니다. 국제 GT ×1.25는 평가 변형이며 훈련 증강에는 포함하지 않았습니다.

## 후보 재현율과 시간

같은 robust 검색의 후보는 학습 전후 동일합니다. 두 GT 결측에서 한글 **1,156/1,191**, 비한글 **11,024/11,031**이 후보에 있습니다. 누락은 **한글 35·비한글 7 = 42행**입니다. 다른 네 조건은 두 언어 모두 후보 재현율 100%입니다.

두 GT 결측의 전체 증강 오답 127행은 후보 누락 42행과 **후보 내 순위 오류 85행**으로 나뉩니다. 원본 오답 31행은 전부 순위 오류입니다. 질량 조절만으로 후보 누락을 해결할 수 없습니다.

## 훈련 보존 확인

새 fold3·4에서 원본은 각각 9,862건·9,668건이며, 증강 저장 그룹은 75,041개·73,299개입니다. 모든 원본의 실제 저장 질량 합은 1이고 원본·view 손실이 없습니다. 전체 5-fold의 원본 그룹 후보 ID·순서·라벨·질의/정답/언어 메타데이터와 질량 정책을 이번에 재대조해 모두 통과했습니다. 새 원본 검증 NPZ 37+40=77개는 바이트 동일하고, 이전 116개를 포함해 전체 193개가 같습니다. 원본 X 전체를 새로 생성하거나 이번에 별도 전체 재비교하지는 않았습니다.

| fold | 원본 그룹 / 후보쌍 | 증강 그룹 / 후보쌍 | 원본 질량 비중 | 생성·변환·학습·비교 합계 | 캐시·모델 |
|---|---:|---:|---:|---:|---:|
| 3 | 19,724 / 2,543,679 | 75,041 / 9,651,140 | 53.2296% | 3시간16분35초 | 1.981GB |
| 4 | 19,336 / 2,493,814 | 73,299 / 9,425,975 | 53.4495% | 3시간22분40초 | 2.040GB |

전체 5-fold의 대조군+증강 파이프라인 및 비교 기록 합계는 16시간58분44초, 캐시·모델은 10.008GB입니다. 보고서·RAM은 별도이고 다음 실행의 시간 보장으로 사용하지 않습니다.

분할·fitting 사전·범주 통계는 원본으로 고정했고 증강본은 자신의 원본과 같은 분할에 있습니다. 일부 마스크에서 정답 후보가 빠지면 해당 그룹을 제외하고 남은 그룹에 질량을 재분배하며 정답 강제 추가는 하지 않습니다. `original_mass=0.5`는 유효한 원본+변형이 함께 있는 view의 정책값이지, 모든 저장 질량 중 원본이 정확히 50%라는 뜻이 아닙니다.

## 채택 판단과 다음 실험

아래는 2026-10-25 당시의 판단과 계획입니다. 이후 0.75 전체5-fold는 완료·미채택했고, 0.5를 현재 서버 최고 제출로 유지하는 최신 상태는 문서 상단과 [후속 보고서](gt-reweighting-5fold.md)에 있습니다.

전체 fold는 이미 개발과 선택에 사용한 데이터이며 독립 테스트가 아닙니다. 변형 조건의 평균을 공식 예상 점수로 해석하지 않습니다. 새로운 제출 패키징·학습·서버 검증은 이번 분석에 포함하지 않았습니다.
