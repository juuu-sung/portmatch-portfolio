## 검증 범위와 비교 조건

확인한 결과는 `runs/compare_ch_variants_fold1`, `runs/compare_ch_variants_fold2`입니다. **전체 5-fold 결과가 아닙니다.** 총 4,856행·2,340척이며 질의 수 제한 없이 해당 두 fold 전체를 평가했습니다.

| 항목 | 기준 | CH 추가 실험 |
|---|---|---|
| 학습 특징 | 86개 | 93개 = 기존 86 + CH 7 |
| 캐시 열 | 87개 | 94개 |
| 변환 | `token_phonetic_v1` | `token_phonetic_ch_v1` |
| 공통 제외 특징 | `retrieval_tonnage_rank` | 동일 |
| 외부/내부 분할 | 선박 단위 5-fold / mixed 3-fold | 동일 |
| 학습 | 300회, 6스레드, seed 20261022 | 동일 |
| 후보·OOF 통계·어려운 오답 샘플 | 기존 캐시 | 동일한 값을 보존 |

저장 비교 리포트는 원본→이름→CH 캐시의 파생 관계와 공통 배열 보존을 검증한 완료 결과입니다. 이번 분석에서는 학습 요약·저장 예측 파일의 현재 SHA-256이 리포트에 기록된 해시와 일치함을 확인했습니다. 대용량 캐시 전체를 다시 읽거나 재해시하지 않았습니다.

## 다음 실험과 실행 상태

**현재 93개를 남은 세 fold까지 확대하는 것은 권하지 않습니다.** 다음은 새 CH 7개를 더하는 대신 구 대응 7개를 교체하는 대조 실험을 준비합니다. 기존 94열 캐시를 재사용해 구 7개와 `retrieval_tonnage_rank`를 제외하면 새 CH 7개가 포함된 86개 구성을 만들 수 있습니다.

교체 대상 구 특징은 다음과 같습니다.

- `name_token_context_alignment`
- `name_token_context_weakest`
- `name_token_context_first`
- `name_token_context_last`
- `name_token_residual_context_ratio`
- `name_token_residual_vowel_ratio`
- `name_token_residual_present`

**교체 대조는 아직 구현·실행하지 않았습니다.** 현재 `compare-rankers`의 선택 특징 검증은 기준과 공유하는 구 특징의 삭제를 거부하므로, 명시적인 교체 대조 검증을 먼저 추가해야 합니다. 현재 코드로 바로 실행할 수 있는 비교 명령을 의미하지 않습니다.
