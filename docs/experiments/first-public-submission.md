## 패키지·검증 절차 재점검

기존 ZIP의 코드·모델·인덱스와 패키지 출처를 재확인했습니다. 이전에 실제 ZIP을 별도 프로세스로 실행한 공개 fold0 전체·역순·부분집합·단독 결과는 저장된 예측과 모두 일치했습니다. 이번 공개 표본의 원본 예측도 저장된 fold0 예측과 전부 같았습니다.

5개 분할의 훈련·검증 간 sample ID, 정답 선박, 정규화 이름, 호출부호 중복은 모두 0입니다. 내부 선박 분할도 같은 선박이 여러 fold에 걸치지 않았습니다. 검증 정답을 후보에 강제로 넣거나 학습 특징에 정답·ID를 사용하는 경로, 저장 지표의 계산 오류는 점검 범위에서 발견하지 못했습니다. 원본 12,222행으로 재계산한 지표는 저장 값과 일치합니다. 과거 모든 캐시 바이트를 재계산한 검증은 아니며, 같은 개발 fold를 반복적으로 이용한 모델 선택의 낙관성은 별개로 남습니다.

## 공개 데이터가 검증하지 못한 조건

- 한글 1,191행은 **382척·515개 입력 패턴**이고, fold0 한글 180행은 **56척·83개 패턴**입니다. 패턴은 ID와 입항 연도를 제외한 입력으로 구분했습니다. 반복 행을 선박별로 균등 가중해도 fold0 한글 정확도는 97.7679%이므로 반복 가중치만으로 큰 격차를 설명하지는 못합니다.
- **공개 한글 1,191행 모두 국내·국제총톤수가 유효**합니다. 국제 GT가 정답 카탈로그 GT와 정확히 같은 행이 852행(71.54%)이며, 국제 GT의 최대 상대오차는 8.54%입니다. 이 상대오차는 두 GT 중 큰 값을 분모로 계산했습니다. 한글 톤수 결측·큰 오차 조건은 기존 검증에 없습니다.
- 공개 비한글은 정규화 이름 정확일치 7,137/11,031행(64.70%)이며 모두 정답입니다. 이름이 정확히 같지 않은 3,894행도 99.6662%, 양쪽 GT가 없는 793행도 99.7478%입니다. 비한글에서의 강건성이 한글에도 성립한다고 볼 수 없습니다.

이 내용은 공개 데이터의 범위를 보여줍니다. 비공개 테스트에 실제로 톤수 결측이나 특정 표기 변형이 얼마나 있는지는 알 수 없습니다.

## 공개 표본의 톤수 변형 실험

학습·인덱스·코드를 바꾸지 않고, 공개 fold0에서 고정 seed `20261023`으로 섞은 뒤 선박당 한 행을 남겨 한글·비한글 각 48척, **총 96척**을 선택했습니다. 같은 행에 원본, 두 GT 결측, 국제 GT만 1.25배의 세 조건을 적용했습니다. 기존부터 GT가 없던 비한글 2행은 변형 전후 값이 같아 각 변형의 실제 변경 입력은 94행입니다. 총 288회 행 추론은 로컬에서 모델·입력 로드를 포함해 **26.25초** 걸렸습니다. 이 측정은 별도 진단 프로세스이며 제출 ZIP 전체 실행 시간과 다릅니다.

| 입력 조건 | 한글 정답 / 48 | 한글 정답 후보 포함 / 48 | 비한글 정답 / 48 | 비한글 정답 후보 포함 / 48 |
|---|---:|---:|---:|---:|
| 원본 | 47 (97.92%) | 48 (100%) | 48 (100%) | 48 (100%) |
| 국내·국제 GT 모두 결측 | **31 (64.58%)** | **31 (64.58%)** | 48 (100%) | 48 (100%) |
| 국제 GT만 1.25배, 국내 GT 유지 | **25 (52.08%)** | **31 (64.58%)** | 47 (97.92%) | 48 (100%) |

두 변형 모두 한글 정답 17척이 후보에서 사라졌습니다. GT 결측 조건에서 후보에 남은 31척은 모두 정답이지만, 국제 GT 변형에서는 후보에 남은 31척 중 6척도 순위에서 틀립니다. 따라서 **검색 누락과 순위 모델의 톤수 오류 민감도를 분리해 개선해야 합니다.** 결측 조건의 한글 평균 후보 수는 2,534.40개에서 85.52개로 줄었습니다. 기존 공개 검증의 후보 재현율 100%는 정확한 톤수 검색이 한글 이름 검색의 약점을 보완한 결과일 수 있습니다.

현재 검색 코드는 유효한 국제 GT를 먼저 사용하고, 그 범위에 카탈로그 후보가 하나도 없을 때만 국내 GT로 재검색합니다. 국제 GT가 틀려도 다른 선박 후보가 있으면 국내 GT 범위는 생략됩니다. 국제 GT 변형에서 누락된 17척 모두 원래 국내 GT의 검색 허용 범위 `abs(query - catalog) / catalog <= 0.10` 안에 있었습니다. **두 GT 범위를 합치면 이 17척을 후보에 포함할 수 있다는 사후 확인**이며, 개선 코드를 실행하거나 최종 1위 회복을 확인한 결과는 아닙니다.

이 실험은 공개 입력에 인위적인 결측·오차를 준 진단입니다. 실제 Public 오답을 확인한 결과나 숨겨진 데이터의 분포 추정, 독립 성능 평가로 해석하지 않습니다.

## 다음 실험 순서

후속 상태: 아래 1·2의 [검색 확장과 비교 도구를 구현](robust-retrieval.md)했고, [fold0 전체 비교·분석](robust-retrieval-fold0.md)까지 완료했습니다. 다음은 robust로 새 OOF 특징 생성·86개 재학습이며 아직 실행하지 않았습니다. 아래 진단 수치는 변경 전 기록으로 보존합니다.

1. **톤수 없이도 작동하는 한글 이름 후보 검색**을 강화합니다. 토큰·문맥 음차 표현을 후보 검색에도 연결하고 원래 검색 경로와 합칩니다. 원본과 GT 결측 입력에서 후보 재현율을 먼저 비교합니다.
2. **국내·국제 GT의 후보 범위를 함께 사용**하는 통제 실험을 준비합니다. 한쪽이 틀린 경우의 검색 회복, 원본 신규 오답, 후보 수의 중앙값·상위 95%·최대값과 실제 실행 시간을 함께 측정합니다. 후보가 바뀌므로 기존 후보 캐시를 그대로 쓴 특징 추가 실험과 구분합니다.
3. 검색을 보완한 뒤 **훈련 부분만으로 톤수 결측·오차 변형을 생성**하는 순위 학습 실험을 설계합니다. 외부 검증 원본은 보존하고 변형 진단은 별도 보고합니다. 후보에 정답이 있어도 틀린 6척 같은 사례의 회복을 확인합니다.
4. **전체 데이터 훈련 전략은 별도 실험**으로 비교합니다. 현재 fold0이 제외한 20% 데이터를 활용하면 조회 범위가 늘 수 있지만, 18.89%p 격차가 해결된다고 약속할 근거는 없습니다. 앙상블은 서버 실행 비용을 별도로 확인해야 합니다.

CH 구 7개→새 7개 교체는 우선순위를 낮춥니다. 현재 86개 모델은 고정 대조군이며, 새 검색은 선택적 실험으로 구현했습니다. 실제 재학습·새 제출 ZIP 생성은 아직 하지 않았습니다. 개별 검증 선박을 위한 예외 규칙이나 테스트 행끼리의 사전 갱신·투표는 사용하지 않습니다. [공식 행별 독립성 규칙](https://dacon.io/competitions/official/236771/overview/rules)
