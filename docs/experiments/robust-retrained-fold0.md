# robust 재학습 fold0 — 미채택과 다음 결측 증강 실험

> 공개용 정리본: 실제 선박별 입력·정답·예측·점수와 행 식별자는 제외했다. 아래 성능표는 실제 실험의 집계 수치이며, 오류의 원리는 별도의 [가상 예시](../fictional-examples.md)로 설명한다.

2026-10-24. **현재 robust 재학습 모델은 채택하지 않고, 같은 설정으로 fold1~4도 진행하지 않습니다.** 기존 86개 기준과 첫 제출 ZIP을 유지합니다. 검색 보강으로 얻은 후보 회복은 유효하지만, 원본만으로 다시 학습한 순위 모델은 원본·국제총톤수 결측의 한글 정확도를 떨어뜨렸습니다. 분석 이후 **훈련 부분에서만 GT 결측 입력을 만드는 fold0 통제 실험을 구현**했습니다. [증강 설계·가중치·실행 명령](gt-missing-augmentation.md). 이후 실제 증강 fold0 실행·분석을 완료했습니다. [증강 결과와 fold1·2 검증 계획](gt-missing-fold0.md)을 참고하세요.

## 검증 범위와 신뢰성

- `runs/compare_robust_retrained_fold0/` 완료. 선박 fold0 전체 **2,452행·1,170척**이며 한글 180행, 비한글 2,272행입니다. 표본 제한이 없습니다.
- 5입력 × 3방법 × 2,452행 = **36,780개 예측**. `baseline`은 기존 검색+86개 모델, `robust`는 새 검색+기존 가중치, `trained`는 새 검색+재학습 가중치입니다. 세 모델의 특징 개수는 모두 86개입니다.
- 독립 감사 **400개 통과, 불일치 0**. 원자료·모델·인덱스·코드 해시, 훈련 분할, 행별·선박별 변화와 지표·시간을 재계산했습니다. 훈련 부분에서 새로 만든 사전·범주 통계도 두 모델과 같습니다.
- baseline과 trained 각각의 원본 2,452행 예측·점수는 저장된 검증 결과와 일치합니다. 이번 baseline/robust 결과는 이전 검색 교체 비교의 예측·점수·후보와도 일치합니다.
- `robust`와 `trained`는 **12,260개 질의×변형 조합 모두 후보 집합 해시·개수·정답 포함 여부가 같습니다.** 이 두 모델의 정확도 차이를 후보 누락 증감으로 설명할 수 없습니다. 정렬된 후보 ID 해시는 검색 순서나 모든 특징 값의 동일성을 직접 검증한 것은 아닙니다.
- 각 GT 변형의 실제 변경 입력은 2,285행입니다. 원래 두 GT가 없는 비한글 167행은 그대로이며, 한글 180행은 모두 바뀝니다.

이 결과는 반복 사용한 공개 개발 fold의 합성 변형 평가입니다. 다섯 조건의 평균을 대회 점수로 만들거나 Public 점수 개선을 보장하지 않습니다. 이번 작업은 저장 산출물 분석이며 코드·모델·ZIP 수정, 장시간 재추론·학습을 하지 않았습니다. **203개 회귀 테스트 통과는 이전 비교 오류 수정 시점의 기록**입니다.

## 정확도: 검색 효과와 재학습 효과를 분리

가중 정확도는 한글 70% + 비한글 30%입니다. 개선·신규 오답은 항상 **같은 입력 조건의 baseline 대비**입니다.

| 입력 | 기존 86개 | 검색만 robust | robust 재학습 | 재학습−기존 | 개선 / 신규 오답 |
|---|---:|---:|---:|---:|---:|
| 원본 | 98.0291% | 98.0291% | 97.2514% | −0.7778%p | 0 / 2 |
| 두 GT 결측 | 75.4604% | 92.5715% | 88.6562% | +13.1958%p | 38 / 6 |
| 국제 GT 결측 | 98.0291% | 94.9180% | 91.0159% | −7.0132%p | 0 / 19 |
| 일반 GT 결측 | 96.8625% | 96.8625% | 97.6403% | +0.7778%p | 2 / 0 |
| 국제 GT ×1.25 | 68.2478% | 81.8530% | 82.3415% | +14.0937%p | 111 / 11 |

| 입력 | 한글 정답: 기존→검색만→재학습 /180 | 비한글 정답: 기존→검색만→재학습 /2,272 | 한글 후보 포함: 기존→새 검색 /180 |
|---|---|---|---|
| 원본 | 175 → 175 → 173 | 2,270 → 2,270 → 2,270 | 180 → 180 |
| 두 GT 결측 | 117 → 161 → 151 | 2,269 → 2,269 → 2,267 | 120 → 172 |
| 국제 GT 결측 | 175 → 167 → 157 | 2,270 → 2,270 → 2,269 | 180 → 180 |
| 일반 GT 결측 | 172 → 172 → 174 | 2,270 → 2,270 → 2,270 | 180 → 180 |
| 국제 GT ×1.25 | 101 → 135 → 135 | 2,194 → 2,223 → 2,260 | 120 → 180 |

두 GT 결측과 국제 GT 오차에서는 기존보다 좋아졌지만, **재학습의 추가 효과**는 다릅니다. 검색만 robust인 모델과 비교하면 두 GT 결측 **−3.9153%p**, 국제 GT 결측 **−3.9021%p**입니다. ×1.25의 추가 **+0.4886%p는 비한글 정답 37행 증가에서만** 나왔습니다. 한글 정답은 135행으로 같으며 16행 개선·16행 신규 오답이 서로 상쇄됐습니다.

| 입력 | 기존→재학습 개선 행·척 / 신규 행·척 | 검색만→재학습 개선 행·척 / 신규 행·척 |
|---|---|---|
| 원본 | 0·0 / 2·1 | 0·0 / 2·1 |
| 두 GT 결측 | 38·12 / 6·2 | 3·1 / 15·5 |
| 국제 GT 결측 | 0·0 / 19·7 | 1·1 / 12·5 |
| 일반 GT 결측 | 2·1 / 0·0 | 2·1 / 0·0 |
| 국제 GT ×1.25 | 111·46 / 11·5 | 55·28 / 18·7 |

척 수는 각 조건·변화 유형 안에서 계산했습니다. 같은 선박이 여러 조건 또는 개선·신규 양쪽에 등장할 수 있어 단순 합산하지 않습니다.

## 후보 수와 시간

이번 동일 실행에서 측정한 baseline→trained입니다. 검색만 robust와 trained의 후보 수는 같고, 총 추론 시간 차이는 −0.41~+0.48%입니다.

| 입력 | 평균 후보 기존→재학습 | p95 / 최대, 재학습 | 전체 추론 초 기존→재학습 | 시간 증가 |
|---|---:|---:|---:|---:|
| 원본 | 2,612.2 → 2,656.8 | 4,707.2 / 7,082 | 300.59 → 324.73 | +8.03% |
| 두 GT 결측 | 153.0 → 174.0 | 362 / 421 | 227.27 → 259.69 | +14.27% |
| 국제 GT 결측 | 2,614.3 → 2,634.5 | 4,698.4 / 5,010 | 376.59 → 407.05 | +8.09% |
| 일반 GT 결측 | 2,612.2 → 2,632.4 | 4,694 / 5,010 | 392.87 → 424.86 | +8.14% |
| 국제 GT ×1.25 | 2,349.6 → 4,830.5 | 8,076 / 8,718 | 274.72 → 415.34 | +51.18% |

원본 한글 행만의 시간은 **15.75→37.91초, 2.41배**입니다. ×1.25 평균 후보는 2.06배입니다. 전체 실행 88분 11초는 15조건 전체와 초기화·출력의 합이며, 단일 모델 추론 시간이나 서버 예상 시간이 아닙니다. 이전 실행과 절대 시간을 직접 비교하지 않고 같은 실행 내 비율을 사용합니다. 운영체제·문자열 캐시와 실행 환경 영향이 남습니다.

## 다음 실험: 훈련 query의 GT 결측 증강

원본 훈련 분포를 확인했습니다. fold0 훈련 **9,770행 중 한글 1,011행은 모두 두 GT가 유효**합니다. 전체 훈련에서 한쪽 GT만 없는 예시는 **0행**이고, 두 GT 결측 626행은 전부 비한글입니다. 유효한 국제 GT 9,144행은 정답 카탈로그 GT와 상대차이 `abs(국제GT−카탈로그GT)/카탈로그GT`가 10%를 넘는 사례가 없습니다. 이번 robust 모델은 이 원본 입력의 **19,540 OOF 그룹**으로 학습했으며 GT 증강은 없습니다.

따라서 새 후보로 다시 학습한 것만으로는 결측·큰 오차 조건의 순위를 배울 충분한 예시가 생기지 않았습니다. 이는 **훈련·평가 입력 분포 차이를 보여주는 근거**이지 특정 특징 하나가 오답을 만들었다는 인과 증명은 아닙니다.

**후속 구현 완료:** `--gt-augmentation missing --original-mass 0.5`와 증강 없는 robust 모델을 함께 넣는 네 방법 비교를 준비했습니다. [새 출력 경로의 네 단계 명령](gt-missing-augmentation.md#vs-code-powershell-실행)을 사용합니다. 완료된 robust 캐시·모델·비교 폴더는 재실행하지 않습니다.
