**기존 이득의 유지 여부와 두 모델의 차이**

차이의 단위는 %p다. 대괄호는 선박 단위 paired Poisson bootstrap5,000회의95% 구간이다. 반복 모델 선택·다중 비교·숨겨진 Public 분포 변화를 보정한 구간은 아니다.

|---|---|---|---|
| 원본 | -0.3102 [-1.0607, +0.4301] | +0.1121 [-0.1968, +0.5098] | +0.4223 [-0.3221, +1.1613] |

| 순서 교환+두 GT ×0.70 | -1.9667 [-3.8791, -0.0565] | -2.2280 [-4.1674, -0.3559] | -0.2612 [-1.9156, +1.3188] |
| 기존 2글자 삭제+두 GT ×1.50 | +0.4466 [-1.5557, +2.4271] | -0.7234 [-2.7048, +1.2495] | -1.1700 [-2.6758, +0.2514] |

- **원본:** 집중 오답은 직전 대비+0.1121%p로 합산 성능을 유지했다. 95% 하한−0.1968%p도 사전 허용 손실−0.25%p 안에 있다. 다만 총 오답 수는25→25행으로 같고 한글 오답18→16·비한글7→9의 구성 변화가 점수를 올렸다. 기본 보강은−0.3102%p로 점 추정상 유지 기준을 넘는 손실이다.
- **×0.70:** 기본 보강−1.9667%p·집중 오답−2.2280%p로 두 모델 모두 직전 이득을 완전히 유지하지 못했다. 95% 구간도 각각[−3.8791,−0.0565], [−4.1674,−0.3559]다. 각 모델에서5개 fold 중4개가 하락했다. 한글 정답은 직전891→858 / 853행으로 줄었다. 그럼에도 기존 최고보다 각각+14.4770 / +14.2158%p 높다.
- **×1.50:** 기본 보강은 합산+0.4466%p로 점수상 유지했지만, 구간 하한이−1.5557%p라 유지가 확정된 것은 아니다. 집중 오답은−0.7234%p이며4개 fold에서 하락했다. 한글 정답737→719행 손실을 비한글10443→10566행 개선으로 상쇄하지 못했다. 이 하락의 구간에는0이 포함된다.
- **이름 단독 오류:** 기존1글자 삭제에서 집중 오답−1.3572%p이고 모든 fold가 하락했다. 기본 보강은 기존2글자 삭제에서−1.4568%p다. 강한 톤수 오류를 고치는 동안 일부 이름 단독 오류의 성능을 잃었다.

집중 오답과 기본 보강만 비교하면 ×0.55는 **+0.9105%p [−0.2673,+2.1594]**다. 한글 정답은16행 늘지만 비한글은11행 줄어 순5행 증가이며, 확실한 우위로 일반화하기에는 구간이0을 포함한다. 원본+0.4223%p도 같은 한계가 있다. 반면 ×1.50은 집중 오답이 기본 보강보다−1.1700%p이며 역시 구간에0이 포함된다.

국제 GT 결측(+0.4223%p)과 국제 GT×1.25(+0.4811%p)는 집중 오답의 추가 효과 구간이0보다 높지만, 여러 비교 중 일부이며 다중 비교 보정은 하지 않았다. **전체적인 큰 개선은 두 모델에 공통으로 들어간 보강 정책에서 나타났고, 집중 오답의 추가 효과는 조건별 이득과 손실이 섞였다.**

사전 고정한15조건의 허용 손실−0.25%p 기준에서 기본 보강+검색은6조건, 집중 오답+검색은4조건이 실패했다. 집중 오답의 실패 조건은 이름1글자 삭제, 순서 교환+GT×0.70, 기존2글자 삭제, 기존2글자 삭제+GT×1.50이다. 두 모델 모두 엄격한 개발 유지 기준은 통과하지 못했다.

기존 원본과 과거 예제를 보존했어도 과거 비원본 증강 질량 일부를 이번 예제로 옮겼고 모델을 다시 학습했다. 따라서 원본 예제 보존이 모든 이전 오류 조건의 유지로 이어지는 것은 아니다. 특정 학습 질량 이동이 손실의 직접 원인인지, 새 예제 내용이나 제한된 트리 수의 영향인지까지는 이번 두 모델 비교만으로 분리되지 않는다.

**새로 고정한 조건에서도 효과가 나타났다**

이름 유지+GT×0.45에서 집중 오답은 직전77.4679→94.1885%, 새2글자 삭제+GT×0.45는50.9383→72.3083%다. 이름 유지+GT×1.80은76.3828→94.6396%, 새2글자 삭제+GT×1.80은51.7755→72.0427%다. 네 조건 모두 기존 최고보다도 높고, 해당 차이의 구간이0보다 높다.

0.45/1.80은 학습에 사용하지 않은 배율이지만 학습 범위0.4~2.5 안에 있으며, 같은 공개 검증 선박에서 만든 합성 입력이다. ×0.55 한 점의 개선에만 그치지 않았다는 근거는 되지만 독립적인 Public 성능 증거는 아니다.

**실행 적용률과 감사 범위**

5개 fold 합계로 기존 원본 캐시371,868그룹·직전 조합 증강92,627그룹을 유지하고 **90,594개 추가 그룹**을 학습했다. 원본별 상대 질량을 고정하고 두 새 모델의 그룹 수·후보 수·질량이 같다는 실행 당시 검사를 확인했다. 이 그룹 수는 fold와 내부 관점에 걸쳐 반복된 학습 그룹이며 고유 선박 수가 아니다.

추가 검색으로 회복한 정답333그룹을 두 모델 모두 학습했다. 유효 GT 없음5,944·정답 후보 없음838·옮길 증강 질량 없음400그룹은 건너뛰었다. 집중 오답 정책으로 선택이 달라진 것은8,974그룹, 추가 그룹의9.91%다. 선택된 추가 검색 오답의 누적 노출은126,345→346,451개로2.74배 늘었다. 나머지 학습 조건이 같아 이 두 모델 간 차이는 오답 선택 효과로 해석할 수 있다.

이번 재검증에서 **기존 보호 파일9,296개**, 새 fold 파일1,502개(증강 조각1,417개·native 모델10개 포함)의 해시를 확인했다. 전체 예측의 분할·분모·분자,20조건×7방법의 성능, 모든 쌍별 개선/퇴행 행·선박 수, 언어/이름 변형별 순위 오류, 검색 효과와 유지 기준의 점 판정을 재계산했다. 이전16조건의 기준 모델3개 예측과 점수는 부모 실험과 정확히 일치한다.

공통 후보 특징·점수 불변과 학습 그룹·질량 검사는 고정된 실행 코드 및 해시가 일치하는 완료 감사 기록으로 확인했다. 이번에는 학습·전체 검색·특징 생성·5,000회 bootstrap을 다시 실행하지 않았다. 95% 구간은 완료 보고서에서 읽었으며 차이의 점 추정은 원본 예측으로 대조했다. 구현 당시42개 테스트 기록은 유지하고 분석·문서 작업에서 전체 테스트를 반복하지 않았다.
