기록일: 2026-10-23. **86개 특징 모델을 새 개발 기준으로 채택합니다.** 전체 가중 Top-1이 97.0368%에서 98.9067%로 높아졌고, 5개 fold 중 4개가 개선됐습니다. 69개 모델과 원본 캐시는 이후 실험의 대조군으로 보존합니다. 비한글 정확도 하락과 fold 1의 퇴행이 남아 있어 최종 제출 모델 확정과는 구분합니다.

## 비교 범위와 통제 조건

- 외부 선박 5-fold 전체 12,222행: 한글 1,191행, 비한글 11,031행. 빠진 fold나 질의 수 제한은 없습니다.
- 이전 69개 모델에 토큰·문맥 음차·모음·접미 특징 17개를 추가했습니다. 원본 70열 캐시를 87열로 변환하고, 두 모델 모두 `retrieval_tonnage_rank`를 제외합니다.
- 후보 검색, 내부 OOF 통계, 후보 ID·순서, 정답, 어려운 오답·무작위 오답 샘플과 학습 설정을 유지했습니다. LambdaRank 300회, CPU 6스레드, seed 20261022입니다.
- 새 이름 특징은 질의의 원래 이름과 고정 카탈로그 이름만 사용합니다. 개별 검증 선박의 정답이나 예외 매핑을 추가하지 않았습니다.
- 전체 점수는 언어별 예측을 합쳐 계산합니다. fold 점수를 단순 평균하지 않습니다.

## 검증 근거와 한계

로컬 근거는 `runs/compare_token_phonetic_5fold/`의 비교 리포트·요약·행별 변화·선박별 변화와 `work/token_phonetic_5fold_analysis/`의 감사·재추론 진단입니다. 이 원본 파일, 데이터, 모델과 캐시는 GitHub에 올리지 않고 본 문서에는 집계와 해석을 기록합니다.

비교 생성 과정은 현재 원본→파생 캐시의 파일 해시와 보존 기록을 검사했습니다. 69개 기준 모델에는 과거 학습 당시의 모든 캐시 파일 해시가 없으므로, 현재 캐시와 저장 메타데이터의 일치가 과거 모든 파일 바이트의 증명은 아닙니다. 이번 분석은 저장 결과와 사례 재추론을 확인했으며 전체 특징 재생성·모델 재학습을 하지 않았습니다.

모든 fold를 반복적으로 개발 판단에 사용했습니다. 이 결과는 독립적인 최종 성능 추정이나 대회 리더보드 점수가 아니며, 최종 전체 훈련 방식·제출 인터페이스·환경별 추론 시간과 메모리는 별도 검증이 필요합니다.
