# 복합 오류 증강·어려운 오답 재학습: 전체 5-fold 결과

> 공개용 정리본: 실제 선박별 입력·정답·예측·점수와 행 식별자는 제외했다. 아래 성능표는 실제 실험의 집계 수치이며, 오류의 원리는 별도의 [가상 예시](../fictional-examples.md)로 설명한다.

2026-10-30 완료. **증강 확대는 이름 오류와 부가정보 결측에서 효과가 있었지만, 큰 톤수 오차와 이름 오류가 겹친 조건에서 퇴행했다. 현재 어려운 오답 선택의 추가 효과는 작고 일관되지 않다. 기존 최고 제출은 유지한다.**

공개 데이터 12,222행·5,851척, 한글 1,191행·비한글 11,031행의 외부 선박 5-fold를 모두 평가했다. 12조건 × 3모델로 총 439,992개 예측이다. 점수는 언어별 정답 수와 분모를 먼저 합산한 `0.7 × 한글 정확도 + 0.3 × 비한글 정확도`이며 fold 점수 평균이 아니다.

A는 현재 최고 Public 0.8424607623(사용자 보고)을 낸 robust·86개·GT 결측 증강0.5 설정의 기존 fold별 모델이다. 실제 최고 제출 모델은 그중 fold0이다. B는 증강 확대, C는 B에 교차 학습 모델의 어려운 오답 선택을 추가한 모델이다. 아래 전체 5-fold 점수는 단일 제출 모델의 Public 점수가 아니며 새 제출은 하지 않았다.

## 1. 전체 성능과 두 단계의 효과

단위: 정확도 %, 변화량 %p. **B−A는 증강 확대 설정 전체의 효과, C−B는 어려운 오답 선택만의 추가 효과**다.

| 조건 | A 기존 | B 증강 확대 | C 증강+오답 | B−A | C−B | C−A |
|---|---:|---:|---:|---:|---:|---:|
| 원본 | 98.7385 | 98.7440 | 98.8055 | +0.0054 | +0.0615 | +0.0669 |
| 두 GT 결측 | 93.6568 | 93.8919 | 93.5365 | +0.2351 | -0.3554 | -0.1203 |
| 국제 GT 결측 | 98.5595 | 98.7440 | 98.8055 | +0.1845 | +0.0615 | +0.2460 |
| 일반 GT 결측 | 98.7385 | 98.8028 | 98.8643 | +0.0642 | +0.0615 | +0.1257 |
| 국제 GT ×1.25 | 97.8542 | 98.5035 | 98.4474 | +0.6492 | -0.0561 | +0.5932 |
| 두 GT ×1.25 | 92.6152 | 92.1765 | 92.7273 | -0.4386 | +0.5507 | +0.1121 |
| 국적·선종 결측 | 98.3081 | 98.9709 | 98.8561 | +0.6628 | -0.1148 | +0.5480 |
| 모든 부가정보 결측 | 84.4897 | 87.6265 | 87.9203 | +3.1368 | +0.2939 | +3.4307 |
| 이름 문자 삭제 | 93.5818 | 95.7852 | 96.4878 | +2.2033 | +0.7026 | +2.9059 |
| 이름 삭제 + 두 GT 결측 | 76.2982 | 77.7189 | 77.5796 | +1.4207 | -0.1393 | +1.2814 |
| 미학습 문자 순서 교환 | 91.5117 | 94.2468 | 94.0226 | +2.7350 | -0.2242 | +2.5108 |

### 증강 확대의 효과

- 모든 부가정보 결측: +3.1368%p, 85행·29척 회복 / 24행·9척 신규 오답. 5개 fold 모두 개선했다. 한글 정답은 929→982행이다.
- 이름 문자 삭제: +2.2033%p, 145행·75척 회복 / 15행·5척 신규 오답. 4개 fold 개선, fold2는 −0.130%p였다. 한글 +33행·비한글 +97행이다.
- 학습에 넣지 않은 문자 순서 교환: +2.7350%p, 160행·84척 회복 / 20행·12척 신규 오답. 증강 확대의 이득이 미학습 이름 오류에도 일부 일반화됐다.
- 이름 삭제+두 GT 결측: +1.4207%p지만 회복의 순증은 한글 +17행·비한글 +155행이다. 특히 중요한 한글 복합 오류는 여전히 약하다.
- 원본: +0.0054%p로 사실상 비슷하다. 한글 정답 1,170행은 같고 비한글만 2행 증가했다. 원본 오답은 A 31행·20척 → B 29행·17척이다.
- 미학습 순서 교환+두 GT ×0.70: **−3.5830%p**, 169행·85척 회복 / 291행·148척 신규 오답. 한글 −58행·비한글 −64행이며 5개 중 4개 fold가 악화됐다.

### 어려운 오답 재학습의 추가 효과

C−B로 보면 문자 삭제 +0.7026%p, 두 GT ×1.25 +0.5507%p, 모든 부가정보 결측 +0.2939%p의 이득이 있다. 그러나 두 GT 결측 −0.3554%p, 문자 순서 교환 −0.2242%p, 이름 삭제+두 GT 결측 −0.1393%p의 손실도 생긴다.

가장 나쁜 복합 오류에서는 C가 B보다 +0.8467%p 회복하지만 A보다 여전히 −2.7362%p다. **현재 54열 보조 모델·최대64개 오답 교체·추가 증강 그룹에만 적용한 설정에서, 오답 선택을 기본값으로 채택할 근거는 부족하다.** 모든 hard-negative 방법이 효과 없다는 결론은 아니다.

## 2. 선박 단위 불확실성

같은 선박의 여러 행을 하나의 재표집 단위로 묶은 paired Poisson bootstrap 5,000회의 95% 구간이다. 개발 자료 내 기술적 구간이며 반복 모델 선택·다중 비교·Public 분포 차이를 보정하지 않았다. 서로 다른 오류 조건도 독립 표본으로 간주하지 않는다.

| 두 GT 결측 | +0.2351 [-1.232, +1.692] | -0.3554 [-1.389, +0.635] |
| 국제 GT 결측 | +0.1845 [-0.751, +1.114] | +0.0615 [+0.000, +0.190] |
| 일반 GT 결측 | +0.0642 [-0.850, +0.952] | +0.0615 [+0.000, +0.190] |

증강 확대는 부가정보 전체 결측·문자 삭제·문자 순서 교환에서 구간 전체가 양수다. 가장 심한 복합 오류의 구간은 전체가 음수다. 반면 **C−B의 모든 조건 구간은 0을 포함**한다. 원본 구간의 하한 0도 작은 2척 회복의 불확실성을 반영한다. 이를 안정적인 추가 개선으로 단정하지 않는다.

## 3. 실제 최고 제출과 같은 fold0 비교

fold0 검증은 2,452행(한글180·비한글2,272)이다. 전체 합산에서 좋아 보여도 실제 교체 후보의 손실은 별도로 확인해야 한다.

## 5. 성능의 상한과 실패 원인

세 모델은 같은 후보와 같은 86열 특징 배열로 점수를 계산했다. 후보 수·정답 포함 여부가 전행에서 같으며 검색 인덱스도 고정했다. 따라서 이번 정확도 변화는 순위 모델에서 발생한 변화다. 후보 누락 문제 자체는 남아 있다.

| 조건 | 가중 후보 재현율 | 한글 후보 누락 / 1,191행 | 한글 순위 오류 A→B→C |
|---|---:|---:|---|
| 두 GT 결측 | 97.9239% | 35 | 72 → 68 → 74 |
| 모든 부가정보 결측 | 97.9239% | 35 | 227 → 174 → 169 |
| 이름 삭제+두 GT 결측 | 89.8582% | 172 | 216 → 199 → 201 |
| 순서 교환+두 GT ×0.70 | 81.2458% | 314 | 250 → 308 → 296 |

이름 삭제+GT 결측에서는 한글 정답 후보가 14.44%의 행에서 없고, 가장 심한 복합 오류에서는 26.36%에서 없다. 순위 재학습만으로 이 누락을 회복할 수 없다. 동시에 가장 심한 조건의 한글 순위 오류도 250→308/296행으로 늘어, 검색 문제만으로 이번 퇴행을 설명할 수 없다.

코드와 결과에서 뒷받침되는 해석은 다음과 같다.

1. **학습한 오류 조합의 범위가 좁다.** 이름 삭제+GT 결측은 증강하지만 이름 문자 변형+틀린 GT 값을 동시에 만드는 증강은 없다. GT 단독 변형도 0.85/1.15배다. 이름 교환 단독은 좋아지고 같은 이름 교환에 GT×0.70을 더하면 나빠지는 결과는, 틀린 수치가 남아 있는 상황의 정보 충돌을 충분히 학습하지 못했다는 해석과 맞는다. 다만 이번 평가에는 순서 교환+결측이나 순서 교환+다른 GT 배율을 모두 교차한 대조가 없어 결측/잘못된 수치/오류 강도의 인과 효과를 완전히 분리하지 못한다.
2. **학습에서 사용하는 단서의 비중이 달라졌다.** fold별 정규화한 gain 비중의 평균에서 검색 경로 수는 A 5.97%→B 13.90%→C 18.54%, 최선 톤수 차이는 5.53%→8.69%→7.62%, 국적·선종 특징 전체는 8.14%→5.36%→5.56%다. 부가정보가 사라진 경우의 개선과, 이름·톤수 정보가 동시에 틀린 경우의 취약성을 설명할 단서다. 특징 간 상관이 있으므로 gain은 인과적 기여도나 실제 입력 변화에 대한 민감도 증명이 아니다.
3. **보조 모델과 최종 모델이 어려워하는 오답이 다를 수 있다.** 보조 모델은 누수 방지를 위해 조회·범주 통계·검색 특징을 제외한 54열과 원본/두 GT 결측만 학습했다. 최종 86열 모델의 복합 오류와 같은 기준으로 오답을 고르는 것은 아니다. 이것은 추가 효과가 제한된 가능한 이유이며, 다른 보조 모델과의 대조 실험으로 확인해야 한다.
4. **증강 확대와 질량 재배분을 함께 바꿨다.** 일반적인 추가 그룹 보유 행은 원본0.5·기존 GT 마스크0.25·추가 오류0.25로 학습한다. B−A는 증강 종류 확대와 기존 마스크 질량 감소를 합친 효과다. 특정 증강 한 종류의 독립 효과나 단순히 데이터 양을 늘린 효과로 해석하지 않는다. C−B는 질의·질량·후보 수가 같아 오답 선택의 추가 효과를 더 직접적으로 비교한다.

## 6. 학습 적용 범위와 검증

5개 fold에 걸쳐 추가 증강 시도 97,776그룹 중 92,627그룹을 저장했다. 입력이 바뀌지 않은 4,912그룹, 정답 후보가 없는 237그룹은 기록 후 제외했다. 같은 공개 행이 여러 외부 fold의 훈련에 반복 포함되므로 이를 독립 원본 92,627건으로 세지 않는다.

| 증강 | 시도 | 저장 | 변화 없음 | 정답 후보 없음 |
|---|---:|---:|---:|---:|
| 국적·선종 결측 | 16,452 | 16,452 | 0 | 0 |
| 문자 삭제 | 16,664 | 16,328 | 336 | 0 |
| 문자 삭제+GT 결측 | 16,436 | 16,265 | 0 | 171 |
| 두 GT 0.85/1.15배 | 15,964 | 14,954 | 980 | 30 |
| 모든 부가정보 결측 | 16,388 | 16,352 | 0 | 36 |
| 띄어쓰기 제거 | 15,872 | 12,276 | 3,596 | 0 |

어려운 오답 선택은 87,592/92,627그룹(94.56%)에서 실제 후보 구성을 바꿨다. 효과가 제한된 이유가 기능이 적용되지 않았기 때문은 아니다. 두 분기의 그룹·질량·후보 수는 동일하다.

실행 당시 저장 결과 감사는 내부/외부 선박 분리, 보조 모델15개, 원본 단위 질량 합1, 추가 후보쌍 라벨·정답 보존·동일 후보 수, 모델 복원과 순서 독립성을 검사했다. 이번 결과 확인에서는:

- 기존 모델·제출물·기존 소스 등 보호 파일348개, 데이터·고정 구현 해시를 다시 확인했다.
- 새 모델10개와 예측 파일5개의 해시를 실행 당시 감사 기록과 대조했다.
- 추가 증강 조각1,449개를 다시 해시 검증했다.
- 전체439,992개 예측의 범위·중복·후보 수·정답 포함,12,222행 원본 baseline의 예측·순위·후보 수·점수를 기존 저장 결과와 재대조했다.
- 조건별 성능과36개 쌍별 개선/퇴행 수를 다시 집계했고 저장 결과와 일치했다.

이번 확인은 저장 결과 분석이다. 장시간 학습·전체 검색·전체 테스트를 다시 실행하지 않았다. 구현 당시384개 테스트와 후속8개 통합 검증 기록은 유지한다. 기존 최고 제출과 모델은 변경하지 않았고 새 Public 점수는 없다.

## 7. 다음 판단

현재 최고 모델을 유지하고, 증강 확대는 다음 실험의 유효한 출발점으로 보존한다. 현재 오답 선택은 기본 설정에 바로 포함하지 않는다. 다음 우선순위는 다음과 같다.

1. 원본·기존 GT 결측 성능을 보호하면서 **이름 오류+유효하지만 틀린 톤수** 조합을 학습하는 대조 실험을 먼저 한다. 현재 오류 조건의 점수만 보고 비율을 반복 조정하지 않고, 질량과 검색을 고정해 증강 구성의 효과를 분리한다.
2. 한글 이름 오류+GT 오류에서 정답 후보 누락을 줄이는 검색 대조를 별도로 한다. 후보 회복과 순위 개선을 서로 다른 지표로 확인한다.
3. 보조 모델의 학습 오류 분포를 최종 과제와 맞춘 뒤, 오답 교체 수와 다양성 유지 여부를 통제해 재비교한다. 현재 결과만으로 더 공격적인 오답 선택을 확대하지 않는다.

현재 12조건은 결과를 이미 관측한 개발·회귀 검증이다. 후속 실험에서는 다른 오류 seed/유형의 미관측 검증을 사전에 별도로 정해야 한다. 이 결과로 Public 상승을 보장하거나 검증 조건을 임의 평균해 새 최고 모델을 선언하지 않는다.
