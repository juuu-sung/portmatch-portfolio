# 원본 질량 0.75 전체 5-fold — 미채택, 0.5 유지

> 공개용 정리본: 실제 선박별 입력·정답·예측·점수와 행 식별자는 제외했다. 아래 성능표는 실제 실험의 집계 수치이며, 오류의 원리는 별도의 [가상 예시](../fictional-examples.md)로 설명한다.

## 비교 범위와 검증

- `runs/compare_robust_gt_missing_mass075_fold0`부터 `fold4`까지 완료된 결과를 합산했습니다. 공개 12,222행(한글 1,191·비한글 11,031), 다섯 입력과 다섯 실행 방식의 **305,550개 저장 예측**입니다.
- 외부 선박 5-fold, 내부 OOF 분할, robust 검색, 86개 선택 특징, 후보·라벨·샘플, 학습 300회·6스레드를 고정했습니다. `control`은 같은 원본 캐시의 0.5 모델, `trained`는 질량만 0.75로 바꾼 모델입니다. 기존 86개(`baseline`), 검색만 robust, 증강 없는 robust(`reference`)도 대조했습니다.
- 저장 예측·지표·출처 감사 **20,957개 전부 통과**. 후보 동일성 183,330쌍, 저장 원본 검증 예측 48,888쌍, 이전 0.5 실험 예측 재현 244,440쌍을 확인했습니다. 이 숫자는 검사 종류별 비교 횟수이며 서로 다른 고유 입력 수가 아닙니다.
- 점수는 전체 한글·비한글 정답 수를 각각 합산한 `0.7 × 한글 정확도 + 0.3 × 비한글 정확도`입니다. fold 평균이나 다섯 입력 조건 평균을 공식 예상 점수로 사용하지 않습니다. 반복 사용한 개발 fold이며 독립 테스트가 아닙니다.
- 이번 작업은 저장 결과·캐시 검사와 문서 갱신입니다. 특징 생성·학습·추론·새 ZIP 생성은 실행하지 않았습니다.

### 실제 캐시 보존 확인

출처 검증 대상은 전체 **6,036개 자산·6,006개 NPZ shard**, 원본 검증 NPZ **193개**입니다. fold0·2·3·4의 4,823자산·4,799 NPZ는 이번에 실제 비질량 배열의 비트 동일성까지 다시 검사했습니다. fold1의 1,213자산·1,207 NPZ는 이전 전체 배열 검증 증명을 보존하고, 현재 모든 파일·메타데이터·manifest 해시와 파일 목록이 같음을 다시 확인해 재사용했습니다. fold1의 배열 검사를 이번에 새로 실행한 것은 아닙니다.

기존0.5 캐시는 바뀌지 않았고, 새0.75 캐시의 후보·특징 X·라벨 y·그룹·순서·검증·인덱스·분할·질의 로그도 보존됐습니다. 변경 범위는 훈련 `query_mass`와 관련 질량 진단·출처 정보입니다. 원본당 총질량1과 언어별 질량 합을 유지합니다. 유효 마스크가 없는 view의 재분배 때문에 실제 원본 질량 비중은 **76.5689~76.7248%**이며 정책값0.75와 동일한 숫자가 아닙니다. 모든 모델이86개 특징·300개 트리·6스레드·같은 seed/config인 것도 확인했습니다.

## 후보와 시간

robust 검색을 사용하는 네 실행 방식의 후보 집합·개수·정답 포함은 동일합니다. 두 GT 결측의 후보 누락은 한글 35·비한글 7, 합계 42행이며 다른 네 조건은 후보 재현율 100%입니다. 질량 변경으로 후보 누락은 해결되지 않았고 신규 오답은 모두 순위 오류입니다.

## 채택 판단과 다음 계획

후속 실행 완료(2026-10-26): 아래3번의 전체 공개훈련 경로를 구현하고 실제 공개12,222행의 특징 생성·학습·ZIP 검증까지 완료했습니다. ZIP6조건 예측 일치와 행별 독립성을 확인했으며 원본 전체 실행은 로컬1,281.59초입니다. 구현 당시281개 테스트 기록은 보존하고 새 Public 점수는 아직 없습니다. [전체훈련 실행 결과·완료 명령](../full-training.md). 아래는 이 결과 분석 시점의 판단입니다.

1. **0.75 미채택, 질량 비율만 바꾸는 실험 종료.** 원본 기준 보존을 달성하지 못했고 0.5의 강건성을 잃었습니다. 공개 fold 점수에 맞춘 추가 비율 탐색이나 선박별 예외는 진행하지 않습니다.
2. **robust·86개·0.5를 다음 제출 개발의 고정 설정으로 유지.** 기존 86개는 깨끗한 원본 비교 기준으로 계속 보존합니다. 0.5도 원본 목표를 완전히 충족한 모델은 아니며, 보고된 Public 최고와 변형 검증을 함께 고려한 선택입니다.
3. **다음 우선순위는 전체 공개 훈련 데이터를 사용하는 단일 모델 학습·패키징 경로 준비입니다(미구현 계획).** 현재 제출은 fold0의 훈련 9,770행만 사용합니다. 전체 12,222행을 사용하되 학습 특징은 내부 OOF로 생성하고, 최종 추론 사전·통계는 공개 훈련 전체로 고정해야 합니다. 기존 외부 fold 캐시를 단순 합쳐 중복 소스를 여러 번 학습시키지 않습니다. 현재 CLI는 외부 검증 분할을 전제로 하므로 별도 구현·검증 후 긴 실행 명령을 안내합니다.
4. **후속 품질 개선은 검색 누락과 순위 혼동을 분리합니다.** 두 GT 결측 42행의 검색 누락은 후보 비용과 함께 개선하고, 정답 후보가 있는 이름·번호·잔여 토큰 혼동은 별도 특징/샘플링 실험으로 다룹니다. 이번 0.75에서만 새로 생긴 오류를 고치기 위해 미채택 모델을 계속 수정하지 않습니다.

다음 전체 학습은 설정을 고정한 제출 준비 단계이며 Public 상승을 보장하지 않습니다. 전체 데이터를 학습한 뒤 같은 공개 데이터로 계산한 점수를 새로운 검증 성능으로 보고하지 않습니다. 실제 ZIP 입출력·행별 독립성·추론 시간은 새로운 모델로 다시 검사해야 합니다. 이번에는 새 학습이나 제출을 하지 않았습니다.

사용자 보고 두 번째 점수 **0.8424607623**은 0.5 fold0 제출의 후속 기록이며 첫 점수 대비 +5.1106%p입니다. 제출번호·서버 시간·화면은 추가 확인되지 않았고 0.75의 Public 점수도 없습니다. [두 번째 제출 기록](second-submission.md) · [0.5 전체 결과](gt-missing-5fold.md) · [0.75 fold1 당시 분석과 완료한 나머지 fold 명령](gt-reweighting-fold1.md).
