# 공개 자료와 재현 범위

[프로젝트 개요](../README.md) · [최종 모델 코드 안내](final-model.md) · [실험 근거](experiment-evidence.md)

이 저장소는 1인으로 진행한 PortMatch 프로젝트의 구현·실험·모델 선택 과정을 설명하는 포트폴리오다. 기존 비공개 개발 저장소의 과거 Git 이력을 가져오지 않고, 공개할 파일만 선별해 새 이력으로 구성했다.

## 포함한 자료

| 자료 | 내용 |
|---|---|
| 코드 | 후보 검색, 특징 생성, 순위 학습, 최종 추론, 제출 패키징·검증 구현 |
| 테스트 | 코드에서 직접 구성한 합성 입력·임시 자산을 이용한 검사 |
| 실험 근거 | 조건별 집계 성능, 변화량·신뢰구간, 채택·미채택 판단 |
| 시각자료 | README 요약 이미지, 비교 그래프, 2쪽 포트폴리오 PDF |
| 설명용 오류 사례 | 실제 행과 대응시키지 않고 새로 작성한 [가상 예시](fictional-examples.md) |

## 포함하지 않은 자료

원본 대회 데이터, 카탈로그, 행별 입력·정답·예측, 개별 후보의 점수·특징 벡터, 학습된 검색 사전·매핑·캐시, 모델 가중치, 제출 ZIP을 배포하지 않는다. 실제 행을 인용한 상세 사례도 공개 문서에서 제외했다. 기존 종료 보고서·모델·제출물과 원래 개발 이력은 별도 비공개 보관본으로 보존한다.

문서에 등장하는 `work/`, `runs/`, `artifacts/`, `submissions/` 경로는 당시 실행 위치를 설명한다. 해당 폴더의 실제 데이터 파일이 저장소에 포함되어 있다는 뜻은 아니다. 파일 SHA-256은 출처와 바이트 일치를 확인하는 값이며 파일 자체를 제공하지 않는다.

## 실행할 수 있는 범위

공식 데이터 없이 [집계 검산](experiment-evidence.md#공개-자료-검산)과 [합성 데이터 테스트](final-model.md#공식-데이터-없이-확인할-수-있는-것)를 실행할 수 있다. 실제 최종 모델 추론에는 비공개 모델·검색 자산이 필요하며, 과거 학습 전체를 재현하려면 사용 권한이 있는 공식 데이터와 선행 단계의 산출물이 필요하다.

집계 JSON과 최종 추론 소스는 기존 검증 기록을 유지한다. 문서의 실제 사례만 제거·재구성했으며 성능을 다시 측정하거나 수치를 바꾸지 않았다. 실제 성능표와 가상 설명 예시를 구분해 읽어야 한다.

## 출처와 사용 범위

대회 출처는 [항만 문제해결을 위한 AI 기술 공모전](https://dacon.io/competitions/official/236771/overview/description)이다. 대회 데이터의 취득·이용에는 해당 대회의 조건이 적용된다. 이 저장소는 데이터 접근 권한이나 재배포 권한을 제공하지 않는다.

외부 라이브러리 자체는 포함하지 않으며 [requirements.txt](../requirements.txt)에 의존성을 명시한다. 각 라이브러리의 라이선스가 별도로 적용된다.
