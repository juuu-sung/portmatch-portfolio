## 입력·출력과 행별 독립성

`script.py`는 자신의 위치를 기준으로 두 입력 CSV를 읽습니다. 질의의 필수 8개 열은 `sample_id`, `vessel_name`, `call_sign`, `gross_tonnage`, `international_gross_tonnage`, `flag_name`, `vessel_type`, `arrival_year`입니다. ID와 행 수는 실행할 때 읽으며 고정된 제출 예시 파일에 의존하지 않습니다. 정답 열과 추가 열은 모델 특징에 들어가지 않습니다.

서버 카탈로그는 `vessel_id`로 연결해 저장된 고정 카탈로그와 비교합니다. 카탈로그 행 순서는 달라도 되며, 선박 ID·문자열 속성·수치 값의 호환성을 검사합니다. 각 출력은 공식 카탈로그에 있는 ID여야 하고, `output/submission.csv`는 **입력과 같은 행 수·순서의 `sample_id,target_vessel_id` 두 열**만 저장합니다. 입력 파일은 수정하지 않습니다.

조회 사전·별칭·국적·선종 통계·순위 모델은 저장된 훈련 자산으로 고정합니다. 후보 검색과 특징 계산은 해당 행과 고정 자산만 사용하고, 테스트 전체 통계·그룹 투표·사전 갱신은 없습니다. 문자열 함수의 메모이제이션은 계산 결과를 재사용할 뿐 예측 규칙을 학습하지 않습니다. 실행 로그에는 집계된 진행률과 시간만 남기며 개별 입력·예측 기록을 출력하지 않습니다.

## 제출 전 로컬 ZIP 실행 검증

검증은 ZIP을 케이스별 새 폴더에 풀고 `python -I script.py`로 새 프로세스를 시작합니다. 원래 저장소의 코드를 가져오지 않고 ZIP에 담긴 코드·모델만 실행합니다. 공개 `train.csv`에서 fold0의 보류 검증 행을 가져오되, 제출 프로세스에는 정답 열을 제외한 입력 8열만 넘깁니다. 특징 캐시를 읽지 않고 실제 후보 검색·특징 계산·순위 계산·CSV 저장을 수행합니다.

전체 입력은 한글 180행·비한글 2,272행이며, 부분집합은 한글·비한글 각 32행입니다. 각 실행에서 출력 열·행 수·ID 순서·공식 카탈로그 ID를 검사했고 입력 파일의 실행 전후 해시도 같았습니다. 역순·부분집합·단독 결과는 `sample_id`로 연결해 전체 실행과 비교했습니다.

시간은 **새 프로세스 시작부터 종료까지**이며 Python·라이브러리 import, 패키지 무결성 확인, 모델·카탈로그 로드, 후보 검색, 특징 계산, 추론과 저장을 포함합니다. ZIP 압축 해제와 공개 입력 파일 준비는 제외합니다. 전체 실행 처리량은 약 **8.61행/초**입니다. OS 파일 캐시는 초기화하지 않았습니다. 저장된 학습 요약의 캐시 점수화 시간과 구분합니다.

측정 환경은 Windows 10.0.26200, Python 3.11.9, AMD64 Family 25 Model 97, 논리 CPU 12개가 보이는 로컬 PC이며 LightGBM은 6스레드입니다. **역순 2,452행 실행의 실제 Python 추론 프로세스 최대 Working Set은 452,190,208바이트, 431.24MiB**였습니다. 실행 도중 실제 자식 프로세스에 연결해 OS가 프로세스 시작 이후 누적한 최대값을 확인했습니다. 가상환경 실행기만 측정한 초기 값은 제외했으며, 전체·부분집합·단독 실행의 유효한 최대 메모리 측정값은 없습니다. 이 값은 전체 프로세스 트리의 합계나 Linux 서버의 메모리 보장값이 아닙니다.

## 재현과 남은 확인

새 ZIP 생성·전체 검증 명령은 [TRAINING.md의 첫 제출 ZIP 재현](../TRAINING.md#첫-제출-zip-재현)에 있습니다. 기존 ZIP이나 검증 출력은 덮어쓰지 않습니다. 모델·코드·특징 스키마와 출처 해시를 확인하고 필요한 추론 메타데이터만 복사하므로, 특징 생성이나 학습을 반복할 필요가 없습니다.

위의 상세 실측은 로컬 Docker·WSL 환경 없이 수행한 **Windows 실행**입니다. 이후 DACON의 공식 Linux 서버 제출에서 점수가 산출됐습니다. 별도의 로컬 Linux 재현이나 서버 프로세스 시간·메모리 계측은 하지 않았습니다. 비공개 테스트의 행 수와 행별 후보 수가 공개되지 않아 현재 제출의 시간만으로 새 모델·후보 검색·앙상블의 30분 제한 통과를 보장할 수 없습니다.

현재 ZIP은 첫 제출 결과를 비교할 고정 fold0 기준입니다. 이후 한글 이름 후보 검색과 두 GT 범위 결합을 원본·변형 입력에서 비교하고, 순위 학습·전체 훈련 데이터 활용 전략은 별도로 검증합니다. 이번 진단에서 모델·ZIP을 수정하거나 새 학습을 수행하지 않았습니다.
