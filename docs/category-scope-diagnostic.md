# 검색100% 고정·국적/선종 통계80%·100% 비교

> 공개용 정리본: 실제 선박별 입력·정답·예측·점수와 행 식별자는 제외했다. 아래 성능표는 실제 실험의 집계 수치이며, 오류의 원리는 별도의 [가상 예시](fictional-examples.md)로 설명한다.

2026-10-29. **fold1·3·4 실제 실행·분석을 완료하고 기존 fold0·2와 합친 전체5-fold에서 통계80%를 미채택했습니다.** 원본+0.0588%p의 이득은 한글1행에 집중됐고 국제 GT 결측−0.1175%p, 두 GT 결측6행 개선/9행 신규, ×1.25 5행 개선/4행 신규로 손실도 재현됐습니다. 검색100%·통계100%와 기존 최고 제출 robust·86개·GT 결측 증강0.5 fold0의 Public0.8424607623을 유지합니다. [전체 결과·동일 후보86열·다음 실험](experiments/category-scope-5fold.md). 아래 설계·명령은 완료한 실험의 재현 기록입니다.

구현 검증에서 **전체354개 테스트를77.088초에 통과**했습니다. 기존 특징·학습 소스22개 불변, native 모델39개 검증, 추론 번들4개 로드, 제출 ZIP3개 해시 불변을 확인했습니다. 완료한 사전 규모·2×2 진단의 소스6개도 당시 결과에 기록된 SHA와 같습니다. 아래 실제 모델 사전 점검은 학습 범위·부분집합·자산 연결만 확인했으며 공개 데이터의 새 비교 추론이나 학습을 실행한 결과가 아닙니다.

| fold | 훈련T 행 / 척 | 통계80% M 행 / 척 | 검증V 행 |
|---|---:|---:|---:|
| 1 | 9,816 / 4,681 | 7,803 / 3,744 | 2,406 |
| 3 | 9,862 / 4,681 | 7,834 / 3,744 | 2,360 |
| 4 | 9,668 / 4,680 | 7,709 / 3,744 | 2,554 |

완료한 새 검증은 합계 **7,320행·73,200개 예측**입니다. 저장 결과 감사6,829개 검사가 통과했고 실제 존재하는73,546개 후보의86열 점수를 재계산해 일치했습니다. 기존 fold0·2의 C/D와 합치면12,222행·5,851척·122,220개 예측입니다. 동일 원본 행의5개 조건·두 조합 반복을 서로 다른 검증 표본으로 세지 않습니다. 위354개 테스트와 사전 점검은 구현 당시 기록이며 이번 저장 결과 분석과 구분합니다.

## 두 조합과 비교 방향

| 역할 | 이전 기호 | 실행 이름 | 검색 사전 | 국적·선종 통계 |
|---|---|---|---:|---:|
| 기준 | D | `search100_category100` | 100% | 100% |
| 실험 | C | `search100_category80` | 100% | 80% |

이번 리포트의 변화량은 **C−D, 즉 통계80%−통계100%**입니다. 양수 정확도 변화와 개선 건수는 C가 좋아진 것을 뜻합니다. 이전2×2 리포트의 `category_at_search100`은 D−C였으므로 부호가 반대입니다. 결과를 합칠 때 실행 이름으로 방향을 확인합니다.

두 조합은 같은 fold의 기존 가중치·86개 특징 선택·카탈로그와100% 조회/별칭/TF-IDF/검색 채널을 공유합니다. 국적·선종의 확률/lift 일부만 덮는 대신 **`CategoryCompatibility` 전체**를80% 또는100%로 연결하여16개 범주 특징을 생성합니다. 모델 재학습이나 특징 캐시 변환은 필요하지 않습니다.

초기 준비는 검증된 기존 부분집합 생성 경로를 재사용하므로80% 검색 자산도 메모리에 구성하지만, 이번 두 조합의 검색에는 사용하지 않습니다. 실제 후보 검색은 양쪽 모두 저장 모델의100% 검색 객체를 사용합니다.

## 누수를 막는 고정 조건

- 외부 선박5-fold와 분할 seed20261022를 그대로 유지합니다. 각 fold의 훈련T와 검증V를 저장 모델의 학습 기록에서 확인합니다.
- T 안에서 subset seed **20261027**로 선박 ID를 결정적으로 해시 정렬하고 `floor(0.8 × T의 선박 수)`척을 고릅니다. 선택된 선박의 **원본 행 전체**가80% 통계 집합M입니다. 행 수가 정확히80%라는 뜻은 아닙니다.
- 검색100%와 통계100%는 T만, 통계80%는 M만 사용합니다. V의 행·정답 선박은 모두 제외합니다. M은 이전 fold0·2 진단과 같은 선택 규칙입니다.
- 기존 robust검색·토큰/문맥 음차86개·GT 결측 증강 원본 질량0.5·300회·6스레드 모델을 그대로 불러옵니다. `sample_id`와 정답은 추론 입력에 넣지 않습니다.
- 검증 정답은 모델 점수 계산이 끝난 뒤 정확도 계산과 상세 기록 대상 후보 선택에만 사용합니다. 누락된 정답을 후보에 강제로 넣지 않습니다.

통계80%는 지원도뿐 아니라 확률·희귀 범주의 포함 범위도 함께 바꿉니다. 이 실험의 차이를 지원도4열만의 효과로 해석하지 않습니다. 같은 개발용fold를 이전에도 사용했으므로 새로운 독립 테스트가 아닌 **설정을 고정한 추가 검증**입니다.

## 완료한 VS Code PowerShell 실행 기록

아래 명령으로 각 fold의 **검증 전체 행 ×5개 입력 조건 ×2개 조합**을 계산했습니다. 완료한 출력 폴더에 다시 실행하지 않습니다. 재현이 필요한 경우에는 새 폴더 또는 빈 폴더를 지정하며 각 모델의 저장 설정·학습 범위를 먼저 검사합니다.

```powershell
cd C:\dacon\port

foreach ($fold in @(1, 3, 4)) {
    .\.venv\Scripts\python.exe -m portmatch compare-category-scope --model "artifacts/ranker_robust_gt_missing_token_phonetic_fold$fold" --fold $fold --subset-seed 20261027 --output "runs/compare_category_scope_fold$fold"
    if ($LASTEXITCODE -ne 0) { throw "fold$fold 검색100 고정·범주80/100 비교 실패" }
}
```

기존 `compare-index-factorial`이나 `compare-index-scale` 결과를 새로 만들 필요가 없고 **`--reference`도 받지 않습니다.** D의 원본 예측을 해당 모델의 기존 `validation_predictions.csv`와 대조합니다. 기존 fold0·2 결과 및 그 구현 소스는 보존합니다.

입력은 기본 `work/data/train.csv`, `work/data/vessel_catalog.csv`입니다. 다른 경로를 지정해도 저장 모델의 원본 내용 해시와 같아야 합니다. 중단 후 이어쓰기는 지원하지 않으므로 중단된 출력은 보존하고 `runs/compare_category_scope_fold1_retry1`처럼 새 이름으로 재시도합니다. 완료한 fold를 다시 실행하지 않습니다.

선택적으로 작은 실행을 먼저 확인하려면 별도 폴더를 사용합니다. 이 명령은 필수가 아니며 본 실행에는 `--max-queries`를 빼야 합니다.

```powershell
.\.venv\Scripts\python.exe -m portmatch compare-category-scope --model artifacts/ranker_robust_gt_missing_token_phonetic_fold1 --fold 1 --subset-seed 20261027 --max-queries 64 --output runs/compare_category_scope_smoke_fold1
if ($LASTEXITCODE -ne 0) { throw "fold1 범주80/100 표본 비교 실패" }
```

표본 제한은 검증 질의 수만 줄이며 통계 범위는 같습니다. 표본에 한 언어가 없으면 가중 정확도·재현율은 `null`입니다. 표본 점수를 전체fold 성능으로 보고하지 않습니다.

## 저장 지표와86개 특징

입력 조건은 **원본, 두 GT 결측, 국제 GT 결측, 일반 GT 결측, 양수 국제 GT ×1.25**입니다. 각 조건에서 전체·한글·비한글 정확도, 가중 Top-1(한글70%+비한글30%), 후보 재현율, Recall@5/10/50/100/200, 후보 수, 검색·특징·순위 계산 시간을 비교합니다. 입력 조건들을 한 점수로 평균내지 않습니다.

| 파일 | 내용 |
|---|---|
| `summary.json` | 두 조합의 지표와 C−D 변화, 분할/자산 증명, 특징86개 목록·dtype, 보존·일치 검사와 완료 상태 |
| `predictions.csv` | 전체 질의·조건·조합별 예측, 정답 순위, 후보 수/집합 해시, 점수·시간 |
| `row_changes.csv` | C−D의 행별 개선·신규 오답·오답 유지와 후보/점수 변화 |
| `vessel_changes.csv` | 조건·정답 선박·언어별 개선·신규 오답 집계 |
| `candidate_features.csv` | 정답과 두 조합1위 후보 합집합의 존재 여부·점수·순위·실제86개 특징 |
| `candidate_comparisons.csv` | 동일 후보의 C/D 점수·순위와 변경 특징 수 |
| `feature_changes.csv` | 동일 후보의 실제 바뀐 특징, 이전/이후 값·차이·NaN 전이 |
| `partitions.csv` | 원본 행의 외부 훈련/검증 및80% 통계 포함 여부 |
| `report.md` | 조건별 지표와 개선·신규 오답의 한국어 요약 |

86열 상세 기록은 예측이 바뀐 행에만 한정하지 않습니다. 모든 질의·조건에서 정답과 두 조합1위 후보를 합친 선박 ID를 두 조합에 맞춰 저장합니다. 이는 전체 검색 후보의86열을 모두 저장한다는 뜻은 아닙니다. 값은 모델에 실제 입력한 `float32` 특징이고, 부재 후보는 `present=false`와 빈 값으로 남깁니다. NaN과 부재를0으로 치환하지 않습니다.

## 실행 중 확인과 결과 판단

모든 질의·조건에서 **전체 검색 후보 집합·수·정답 포함 여부가 두 조합 간 동일**해야 합니다. 동일 후보의 **비범주70열도 모두 같아야 하며**, 범주16열만 달라질 수 있습니다. 파일 출력 대상 후보보다 넓은 전체 후보에 이 검사를 적용합니다.

모델 가중치, 특징 선택·검색 자산·카탈로그와 원본 파일의 보존을 확인하고 D 원본을 저장 검증 예측과 대조합니다. 정상 완료한 `summary.json`에서 다음을 확인합니다.

- `complete=true`, `weights_unchanged=true`, `training_assets_unchanged=true`, `protected_files_unchanged=true`, `diagnostic_code_unchanged=true`
- `ranker_shared_by_both_runners=true`, `feature_isolation.verified=true`, `same_search_candidate_invariance_verified=true`
- `parity.saved_original.all_selected_original_predictions_match=true`
- 기본 본 실행의 `coverage.diagnostic_sample=false`, `training_performed=false`, `submission_created=false`

중간 파일이나 `complete=false`는 완료 결과가 아닙니다. `feature_isolation.non_category_candidate_pairs`는 비범주70열을 검사한 후보쌍 수이고 `feature_evidence_counts`는 그중 파일로 내보낸 상세 기록 수입니다. 전체 후보 검사와 선택 후보의86열 저장 범위를 구분합니다.

두 조합의 실행 순서를 번갈아 측정합니다. 행별 시간은 검색·특징·순위 계산이며 초기화·warmup·분리 검사·증거 파일 저장 시간은 별도입니다. 같은 검색이므로 캐시·실행 순서·부하에 따른 작은 시간 차이를 통계 모델의 속도 개선으로 해석하지 않습니다. 서버 추론 시간이나 제한 통과를 검증하는 실행도 아닙니다.

후속 **검색·통계100%를 유지한 지원도 로그4열 제외82개 특징 재학습**은2026-10-30 기준 fold0·1·3·4의 실제 학습·비교 분석까지 완료했습니다. 기존0.5 캐시와 나머지12개 범주 특징을 보존했고 네 fold의 원본+0.1489%p·두 GT 결측+0.9459%p이지만 ×1.25 −0.1421%p와 원본 신규3행이 남아82개 채택은 보류합니다. 같은 설정의 남은 fold2를 검증하며 새 제출은 하지 않았습니다. [네 fold 결과·선박별 분석](experiments/support-ablation-fold0134.md) · [fold2 실행 명령](support-ablation.md). 통계 축소의 손실을 지원도만의 문제로 단정하지 않습니다. 이 고정 모델 진단만으로 전체훈련 Public 하락의 단독 원인이나 새로 학습된 선박의 조회 이득을 확정할 수도 없습니다.
